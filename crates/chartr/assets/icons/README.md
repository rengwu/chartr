# Icons

`agent_antigravity.svg`, `agent_kimi.svg`, and `agent_opencode.svg` are the
unmodified monochrome SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg` version 1.95.0. They are embedded for offline
use and tinted by the app theme. The MIT license is in `LOBE-ICONS-LICENSE`.
